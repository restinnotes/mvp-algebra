## 2024-05-19 - Added ARIA labels to icon-only navigation buttons
**Learning:** Found a recurring accessibility issue pattern in this app where icon-only navigation buttons (e.g., pagination arrows in `PracticeUI.tsx`, step navigation in `ProgressPanel.tsx`, and the back/close button in `WrongProblemModal.tsx`) lacked accessible names. Without ARIA labels, screen readers cannot convey the purpose of these buttons to visually impaired users, resulting in them hearing only "button" when interacting with these controls. This limits the app's overall usability for screen reader users, especially given the extensive use of icon-driven interfaces.
**Action:** When implementing or reviewing icon-only buttons across the design system, always ensure an `aria-label` or visually hidden text is provided to describe the button's action clearly. Added `aria-label` attributes to pagination controls, step navigation buttons, and the back button to improve keyboard and screen reader accessibility.
