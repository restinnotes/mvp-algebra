## 2026-07-04 - Cache Initialization Performance in Knowledge API\n**Learning:** The `src/lib/knowledge.ts` has an explicit `clearCache()` method that resets global state caches. The Next.js API route `/api/questions/route.ts` forces this `clearCache()` on EVERY request to ensure development/data updates are fresh, which defeats the purpose of the in-memory cache and re-parses all JSON files on every search request.\n**Action:** Remove or conditionally execute `clearCache()` in API routes based on environment (`process.env.NODE_ENV === 'development'`) to avoid repetitive file I/O and JSON parsing for every client request.
