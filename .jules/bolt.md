## 2025-01-20 - API Bottleneck due to Synchronous Cache Clearing
**Learning:** Calling `clearCache()` on every POST request in the `route.ts` API handler forced synchronous file system reads (`fs.readFileSync`) to be executed during every request for searching. Since Node.js is single-threaded for synchronous code, this blocked the main thread and caused massive performance degradation under load, effectively serializing all incoming requests and failing to utilize the cached objects.
**Action:** Always verify if cache invalidation logic is actually necessary in production. Wrap development-only cache clearing with `if (process.env.NODE_ENV === 'development')` to avoid catastrophic performance issues in production. Ensure production APIs utilize in-memory caches efficiently without performing sync I/O.
